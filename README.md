# Radha.name index

This public repository indexes accessible pages and records candidate file URLs. It does not download documents or media. The earlier three-file test was blocked; its diagnostic record remains in the manifest. Candidate URLs include site graphics and are not verified downloads.

The crawl resumes the saved queue, prioritizes digital-books pages, follows robots rules, waits at least 10 seconds between requests, and stops when access is refused. A prior request to the images gallery received 403, so that page is excluded. Crawl status and remaining pages are recorded in crawl-manifest.json. This is not a complete index of the site.
